MoltOS

It is an operating system for servers / web apps for ordinary people.

Every app can potentially have both an owner facing UI and a public facing UI (it's own public web server)

E.g. vscode for web can run in the owner facing UI, whilst potentially having a public facing server UI.

The owner UI (needs a better term - admin?) runs in an iFrame in the web frontend

Perhaps it should look slightly closer to a desktop?

Apps have 2 privelage levels: manager and worker

A manager app can create and manage other VMs

A worker app is a leaf node and cannot create other VMs

A manager app cannot have a public facing UI, only admin facing.

A worker app does not have an admin facing UI, but has stats in the admin.

This enables manager apps to manage the creation of VMs for users.

Therefore there should also be a signup ability - user account system baked into it [not firebase].

This allows you to manage users also, like wordpress or shopify.

Potentially being able to run campaigns like shopify also.
